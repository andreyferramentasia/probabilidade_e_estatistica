Como funciona o processo estatístico?

Na Aula 1 vimos que a Estatística está em toda parte e que contagens e taxas podem contar histórias diferentes. Agora vamos abrir o "capô" da Estatística: entender que, por trás de qualquer número divulgado, existe um processo com etapas bem definidas, e conhecer o vocabulário básico que os estatísticos usam para descrever esse processo. Esse vocabulário vai aparecer ao longo de todo o curso, então vale a pena fixar bem cada termo.

Grande abraço, Prof. Andrey

Objetivos de Aprendizagem

Ao término desta aula, vocês serão capazes de:

  • Reconhecer a Estatística como um processo de quatro etapas: definir a população, coletar dados, organizar/analisar e concluir;
  • Diferenciar dados numéricos de dados categóricos e, dentro dos numéricos, dados discretos de dados contínuos;
  • Distinguir população de amostra, e parâmetro de estatística;
  • Identificar o que torna uma amostra aleatória, evitando os erros mais comuns de amostragem tendenciosa;
  • Calcular a margem de erro aproximada de uma amostra e interpretar seu significado.

SEÇÃO 1

Estatística é um processo, não só números

Quem não trabalha com Estatística costuma pensar que ela é só "mexer com números". Na prática, o número final é apenas a ponta do processo. Toda pesquisa estatística séria segue quatro etapas: (1) definir a população que se quer estudar, (2) coletar os dados, (3) organizar, resumir e analisar esses dados e (4) tirar conclusões e responder à pergunta original.

Nenhuma dessas etapas envolve só cálculo. Definir bem a população é uma decisão; coletar dados de forma justa é um desafio prático; e toda conclusão vem com uma margem de incerteza, porque raramente é possível ouvir todo mundo.

Exemplo cotidiano Uma emissora quer saber quem vai vencer a eleição para prefeito. Etapa 1: define a população (eleitores que pretendem votar). Etapa 2: coleta dados de uma parte deles, pois entrevistar todos os eleitores da cidade não é viável. Etapa 3: organiza e resume as respostas. Etapa 4: projeta um resultado para toda a população, já sabendo que pode errar por uma margem pequena.
Exemplo em Tecnologia Um aplicativo de streaming quer saber se um novo algoritmo de recomendações agrada os usuários. Etapa 1: população = todos os usuários ativos. Etapa 2: coleta as notas de satisfação de uma amostra de usuários que já testaram o algoritmo. Etapa 3: organiza as notas e calcula um resumo (por exemplo, a média das notas). Etapa 4: conclui se o algoritmo agrada mais que o anterior, e essa conclusão costuma abrir novas perguntas de pesquisa.
EtapaO que acontece
1. Definir a populaçãoDecidir exatamente quem ou o que será estudado
2. Coletar os dadosEscolher uma amostra e registrar as informações
3. Organizar e analisarResumir os dados em tabelas, gráficos e medidas
4. ConcluirResponder à pergunta original, com sua margem de incerteza
Atenção Nenhuma conclusão estatística tem 100% de certeza, a não ser que toda a população tenha sido consultada. Por isso toda conclusão séria vem acompanhada de uma medida de confiança ou de erro, e não apenas de um número seco.
Fórmula destacada
Definir população → Coletar dados → Organizar/Analisar → Concluir
as quatro etapas do processo estatístico, sempre nessa ordem
Resumo da Seção 1 Estatística é um processo de quatro etapas (população, coleta, organização/análise, conclusão), não apenas um número final.
SEÇÃO 2

Tipos de dados: numéricos e categóricos

Dado é qualquer informação registrada durante a coleta. O conjunto de todos os dados coletados numa pesquisa é chamado de conjunto de dados. Já a característica que está sendo medida ou observada em cada indivíduo (idade, nota, curso favorito) é chamada de variável.

Os dados se dividem em dois grandes grupos. Dados numéricos representam uma contagem ou uma medida (por exemplo, quantos aplicativos alguém tem instalados). Dentro deles, dados discretos só assumem valores que podem ser listados (0, 1, 2, 3...), enquanto dados contínuos vêm de uma medição e podem assumir qualquer valor dentro de um intervalo (por exemplo, o tempo exato de carregamento de uma página). Já dados categóricos representam um grupo ou rótulo (por exemplo, o sistema operacional do celular), e não fazem sentido somados ou calculados como média.

Exemplo cotidiano Numa pesquisa de saúde, "número de consultas no ano" é dado numérico discreto (0, 1, 2...); "peso do paciente em quilos" é numérico contínuo; e "tipo sanguíneo" é dado categórico, mesmo que seja registrado com um código.
Exemplo em Tecnologia Em uma loja de aplicativos, "número de avaliações recebidas" é dado numérico discreto; "tempo médio de uso do aplicativo por dia" é numérico contínuo; e "categoria do aplicativo" (jogo, rede social, produtividade) é dado categórico.
VariávelTipo de dado
Número de seguidores de um perfilNumérico discreto
Duração de um vídeo em segundosNumérico contínuo
Rede social preferidaCategórico
Nota dada a um aplicativo (1 a 5 estrelas)Categórico (ordenado)
Atenção Um número não é sempre dado numérico. O código "1" para Android e "2" para iOS é categórico: somar ou tirar a média desses códigos não tem nenhum significado.
Fórmula destacada
D = {x₁, x₂, x₃, ..., xₙ}
notação de um conjunto de dados D com n observações
Resumo da Seção 2 Dados numéricos medem ou contam (discretos ou contínuos); dados categóricos classificam em grupos. Nem todo número é dado numérico.
SEÇÃO 3

População, amostra, parâmetro e estatística

Como vimos na Aula 1, população é o grupo completo que se quer estudar, e amostra é a parte dele efetivamente pesquisada. Agora vamos além: quando um número resume a população inteira, ele é chamado de parâmetro. Quando o mesmo tipo de número resume apenas a amostra, ele é chamado de estatística. Na prática, quase sempre só é possível calcular a estatística da amostra e usá-la para estimar o parâmetro da população.

Para essa estimativa ser confiável, a amostra precisa ser aleatória: toda amostra possível do mesmo tamanho precisa ter a mesma chance de ser escolhida. Quando isso não acontece (por exemplo, quando só respondem os mais interessados no assunto), a amostra é tendenciosa e o resultado sofre de viés de amostragem.

Exemplo cotidiano O IBGE quer saber a renda média de todas as famílias brasileiras (o parâmetro). Como entrevistar cada família do país é inviável, calcula a renda média de uma amostra de famílias (a estatística) e usa esse valor para estimar o parâmetro da população inteira.
Exemplo em Tecnologia Uma rede social quer saber quantos minutos por dia, em média, todos os seus usuários passam no aplicativo (o parâmetro). Como calcular isso para bilhões de contas seria demorado, o sistema calcula a média de uma amostra aleatória de usuários (a estatística) e usa esse valor para estimar o parâmetro.
TermoRefere-se a
PopulaçãoGrupo completo de interesse
AmostraParte da população efetivamente estudada
ParâmetroNúmero que resume a população inteira
EstatísticaNúmero que resume a amostra
Atenção Quanto maior e mais aleatória a amostra, mais a estatística calculada se aproxima do parâmetro real da população. Amostra grande não compensa amostra tendenciosa: uma amostra pequena e bem escolhida vale mais do que uma amostra grande e viciada.
Fórmula destacada
Margem de erro (%) ≈ 100√n
n = tamanho da amostra; aproximação simples para amostras aleatórias
Resumo da Seção 3 Parâmetro resume a população; estatística resume a amostra. Uma amostra aleatória e suficientemente grande produz uma estatística confiável, com margem de erro pequena.

Exemplo Matemático Resolvido

Um aplicativo de música entrevistou uma amostra aleatória de 625 usuários sobre a satisfação com um novo recurso. Qual é a margem de erro aproximada dessa amostra?

  1. Dados: tamanho da amostra, n = 625
  2. Fórmula: Margem de erro (%) ≈ 100√n
  3. Substituição: Margem de erro ≈ 100√625
  4. Cálculo: √625 = 25; 10025 = 4
  5. Interpretação: a margem de erro aproximada é de 4 pontos percentuais. Se 70% da amostra disse estar satisfeita, o valor real na população inteira provavelmente está entre 66% e 74%.

Exemplo em Python

O programa abaixo recebe o tamanho da amostra e o percentual observado, calcula a margem de erro aproximada e imprime o intervalo provável de resultado na população.

▶Python
import math


def margem_de_erro(tamanho_amostra):
    # margem de erro aproximada, em pontos percentuais
    return 100 / math.sqrt(tamanho_amostra)


def intervalo_estimado(percentual, margem):
    limite_inferior = percentual - margem
    limite_superior = percentual + margem
    return limite_inferior, limite_superior


tamanho_amostra = 625
percentual_satisfeitos = 70

margem = margem_de_erro(tamanho_amostra)
inferior, superior = intervalo_estimado(percentual_satisfeitos, margem)

print(f"Margem de erro aproximada: {margem:.1f} pontos percentuais")
print(
    f"Resultado provável na população: entre "
    f"{inferior:.1f}% e {superior:.1f}%"
)

Entrada: tamanho da amostra e percentual observado.

Processamento: margem_de_erro aplica a fórmula da Seção 3; intervalo_estimado soma e subtrai essa margem do percentual observado.

Saída: "Margem de erro aproximada: 4.0 pontos percentuais" e "Resultado provável na população: entre 66.0% e 74.0%".

Interpretação: o programa transforma o tamanho da amostra em uma faixa de confiança para o parâmetro da população, como no exemplo matemático resolvido.

Escreva um programa em Python que: (a) calcule a margem de erro aproximada dessa amostra; (b) calcule e imprima o intervalo provável de aprovação na população inteira; (c) imprima um alerta se a margem de erro for maior que 8 pontos percentuais, indicando que a amostra é pequena demais para uma conclusão confiável.

Exercício 1

▶Python
import math

tamanho_amostra = 400

margem = 100 / math.sqrt(tamanho_amostra)

print(f"Margem de erro aproximada: {margem:.1f} pontos percentuais")

Saída: "Margem de erro aproximada: 5.0 pontos percentuais".

Comentário: aplicação direta da fórmula da Seção 3, com √400 = 20 e 100/20 = 5.

Exercício 2

▶Python
import math

tamanho_amostra = 150
percentual_aprovacao = 58

margem = 100 / math.sqrt(tamanho_amostra)
inferior = percentual_aprovacao - margem
superior = percentual_aprovacao + margem

print(f"Margem de erro aproximada: {margem:.1f} pontos percentuais")
print(
    f"Aprovação provável na população: entre "
    f"{inferior:.1f}% e {superior:.1f}%"
)

if margem > 8:
    print("Amostra pequena: margem de erro alta, resultado pouco confiável.")
else:
    print("Margem de erro razoável para essa estimativa.")

Saída: "Margem de erro aproximada: 8.2 pontos percentuais", "Aprovação provável na população: entre 49.8% e 66.2%" e o alerta de amostra pequena.

Comentário: com √150 ≈ 12,2, a margem fica acima de 8 pontos percentuais, disparando o alerta. Isso não invalida a pesquisa, mas mostra que 150 pessoas é pouco para cravar um número exato de aprovação.

Retomando a Conversa Inicial

Seção 1, Estatística é um processo: toda pesquisa segue quatro etapas (população, coleta, organização/análise, conclusão), e nenhuma conclusão é 100% certa a não ser que a população inteira seja consultada.

Seção 2, Tipos de dados: dados numéricos contam ou medem (discretos ou contínuos); dados categóricos classificam em grupos, mesmo quando usam códigos numéricos.

Seção 3, População, amostra, parâmetro e estatística: a estatística calculada na amostra estima o parâmetro da população, com uma margem de erro que diminui quanto maior e mais aleatória for a amostra.
